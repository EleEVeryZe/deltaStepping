# 1. CPU
## 1.1 SEQUENCIAL DIJKSTRA

### How to execute
    gcc -O3 dijkstra.c -o dijkstra
    ./dijkstra base de dados. Ex:
        ./dijkstra ../dados/emailEu/Email-EuAll.txt
        
###  How to execute in root
    gcc -O3 ./CPU/dijkstra.c -o ./CPU/dijkstra
    
    Sobre a base:
    ./CPU/dijkstra ./dados/emailEu/Email-EuAll.txt
